# 单标的可复现量化投研 P0 Implementation Plan

> For agentic workers: 经用户另行批准实现后，使用 executing-plans 按任务执行与评审；步骤使用 checkbox 跟踪。本轮只交付计划，所有复选框未执行，不授权业务变更或提交。

**Goal:** 对一只沪深股票取得冻结数据、计算指标/估值、结合公告证据，产出带图表且可离线重算的一页研究摘要与完整卷宗。

**Architecture:** 原 PLAN/COLLECT/ANALYZE/VERIFY/REPORT 主线保持；新增量化数据/计算支路，独立有界 worker、不可变数据/产物 manifest、确定性数值引用。SQLite 管元数据/ownership，Parquet 存冻结数据，DuckDB 只读；旧网页报告与 HTTP/hash 兼容。

**Tech Stack:** 保留 Python/FastAPI/SQLAlchemy/Vue/Vite/DeepSeek；量化 worker Python3.13，核心候选 NumPy2.5.3/pandas3.0.6/Arrow25.0.1/DuckDB1.5.6、AkShare1.19.1/BaoStock0.9.4、ECharts6.1.0/Matplotlib3.11.2。

**Spec:** [完整方案](../../v8-taskL-quant-evolution-plan.md)；[实际数据源 spike](../../spikes/task_l/README.md)。本文细化 P0，第14章管理人日和P1–P3，不在此预实现后续阶段。

## Global Constraints

- 只在用户明确批准后执行；本轮禁止改业务代码/依赖/数据库。
- P0：沪深普通股、单标的、日频<=3年；无回测/选股/实盘/目标价。
- 不放松 VERIFIED/PROBABLE/UNVERIFIED、独立来源族、精确 ENTAILS、引用和防编造；新门禁仅加严。
- 所有数值从冻结产物来；模型不运行任意代码/SQL、不能自定最终状态。
- v1 HTTP默认JSON和历史内容哈希不变；v2 sidecar显式量化schema。
- technical appendix默认折叠；空章不呈现；沿原数字卷宗token、主题、responsive/reduced-motion，不加UI框架。
- Python3.11旧业务不装quant仍启动；新科学计算版本只进入经验证的3.13 worker。
- 操作脏工作区时仅暂存本任务文件；不得提交旧任务A–K改动，迁移下一个revision由实际head决定。

```text
1 契约/许可 ─→ 2 数据适配 ─→ 3 冻结存储 ─→ 4 纯计算
```

**Interfaces:** 消费PriceSeries/MetricSpec/FinancialFact，产出`compute_metrics(*, series: PriceSeries, spec: MetricSpec, benchmark: PriceSeries | None = None, risk_free: tuple[tuple[date, Decimal], ...] = ()) -> tuple[MetricValue,...]`、`valuation_check(*, series: PriceSeries, financials: tuple[FinancialFact,...], asof: datetime) -> tuple[MetricValue,...]`；服务submit/reproduce签名见主方案8.2。pure结果由service绑定job/input/code/env manifest。

```python
from datetime import date
from decimal import Decimal
from marketpulse.quant.contracts import MetricSpec, PricePoint, PriceSeries
from marketpulse.quant.compute.metrics import compute_metrics

def test_return_and_drawdown_have_hand_calculated_values():
    series = PriceSeries(instrument_id="FIXTURE", currency="CNY", adjustment="raw",
        points=tuple(PricePoint(session_date=date(2024, 1, day), close=Decimal(value))
                     for day, value in [(2,"100"), (3,"110"), (4,"99")]))
    spec = MetricSpec(metrics=("return","drawdown"), return_basis="price",
        annual_sessions=252, risk_free_snapshot_id=None, benchmark_snapshot_id=None)
    values = {item.name:item.value for item in compute_metrics(series=series, spec=spec)}
    assert abs(values["return"] - Decimal("-0.01")) < Decimal("1e-10")
    assert abs(values["drawdown"] - Decimal("-0.1")) < Decimal("1e-10")
```
