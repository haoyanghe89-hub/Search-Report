## 本次笔试交付范围

- 无密钥离线案例可重跑：11 个有效归档来源、18 条精确摘录、15 条带限定或明确归因的声明、两轮收集/验证反馈、实际来源口径冲突、17 个报告章节、31 处引用。
- 至少 3 个官方来源条目、3 个不同出版者的二手来源，覆盖官方报告、新闻、学术等类型。出版者多样性不被当作每条声明的独立交叉证实。
- NTSB 原文的焚烧时间修正为当地 16:37；废弃空正文 EPA 跳转页；原创研究不再当作二手报道；不再用事件日期填充所有发布时间。
- 引用可追溯声明、验证依据、精确摘录、来源 URL、发布时间、归档和定位。Markdown 导出保留发布/审核状态与原文来源。
- 时间线中的事实使用已验证声明并带引用；整改、局限和冲突章节展示对应内容。离线方法和局限明确披露。
- 报告为 `REVIEW_REQUIRED`，不是自动批准。去除任意三位数字密码绕过和内置默认审核凭据；审核员必须自行配置 Argon2id 哈希和随机指纹密钥。
- 重复回放检查确认引用属于对应运行；来源家族查询按运行隔离。
- 前端提供新建调查、独立运行、实际状态读取、来源/证据/声明/冲突/时间线、引用弹窗、快照、导出和审核。

这里的 VERIFIED 表示**有依据的限定声明通过当前策略**。例如 STATEMENT 只验证“NTSB 作出了某项陈述”，不自动证明其内容为客观终极事实。全部 15 条展示声明通过，不代表事故已无未知，也不代表模型准确率为 100%。

归档的历史远程抓取时间未完整保留，元数据明确披露 unknown；本次归档入库时间不冒充历史远程抓取时间。离线步骤采用固定时钟及合成端口使用量，不应作为真实模型耗时/Token 成本评测。

## 启动

解压源码包，进入 `Search-Report`，参考 README。

```powershell
Copy-Item .env.example .env
docker compose up --build --wait
```

访问 http://localhost:3000。离线回放无需模型密钥。无 Docker 的本地方式：`uv sync --extra dev --extra web --extra server`，启动 `uv run search-report-api`；另一个终端进入 frontend 执行 `npm ci`、`npm run dev -- --host 127.0.0.1`，访问 http://localhost:5173。

## 尚不能称为成熟 DeepSearch 的部分

1. 必须以真实多事件数据集评估事实覆盖、语义引用正确率、反证召回、拒答质量、成本和延迟；当前离线映射只是可审计演示/回归基准。
2. 需要长文相关段落召回、主动反证、逐问题覆盖评估、跨来源共同信息源识别和更严格的冲突解决策略。
3. 当前本机单进程支持 v4 原运行检查点恢复、未知调用确认和追加预算；服务器重启后可安全自动继续，未知费用或预算耗尽需人工处理；已有进程守护、停滞告警及配套备份演练。分布式持久任务队列、多节点协调和供应商幂等仍未实现。
4. 需要评估再扩大并行研究和动态分工；角色契约与反馈循环不等于成熟自主多智能体团队。
5. 公开服务前需要全接口鉴权、租户隔离、配额、TLS、安全审计；本版本只面向可信本地用户。
6. OCR、复杂表格/动态网页取证、中文叙事质量和多人审核仍有不足。详见 KNOWN_LIMITATIONS.md。

当前结论：本地运行和离线证据链验收已完成，五项 P0 的代码修复已交付；Docker 及真实模型环境验收仍待对应环境完成。
