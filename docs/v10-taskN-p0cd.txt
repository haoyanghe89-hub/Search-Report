重要：所有量化结论必须来自冻结快照上的确定性计算，模型只用于计划/解释/网页语义，不得由模型生成数值；所有计算在子进程，不阻塞 FastAPI。

==== P0-C：指标 / 估值 / 确定性执行（方案 14.1，4–5 人日）====
1. 纯计算模块（无网络、无DB副作用，输入为冻结快照/PriceSeries）：
   - compute/metrics.py：简单日收益、累计收益、年化（CAGR，按elapsed years）、波动率（样本std ddof=1×年化，年化交易日数作为显式假设写入spec，默认252）、最大回撤（含峰/谷/恢复，未恢复不假定恢复日）；首日收益null；停牌carry-forward策略显式，不自动剔坏日。
   - compute/valuation.py：PE/PB（raw价格×当时股数 / TTM归母净利、归母权益，保持同一share basis；注明TTM/静态、归母/合并、总/流通市值、报告版本与日期；负盈利PE标不适用、不排名；金融股不套EBITDA/毛利）；ROE（平均净资产，注明披露或计算）。
   - compute/indicators.py：SMA/EMA、RSI14、MACD，仅作分析辅助；固定窗口/初始化/缺值定义，不凭模型生成。
   - 所有缺失值带原因（不是0）；单位与数值分开存储；展示用格式化（亿元/%），计算不用舍入值。
2. 确定性执行与 manifest：execution/worker.py（有界子进程、硬超时/取消杀进程并等待退出、输出分块限额）、service.py（幂等提交、租约/恢复）、recording.py（计算调用录制/回放）。
   - 每次计算冻结完整 manifest：输入快照 manifest/hash、schema、标准化配置、口径、市场规则/日历、基准/汇率/无风险利率快照、代码Git SHA（脏工作区加源码树hash）、Python/依赖lock hash、seed、输出完整hash、计算参数/单位/采样边界。
   - 复现两级：同环境输出 bytes hash 相同；跨环境按声明中数值绝对/相对误差门槛一致。
3. 数据契约：MetricSpec/MetricValue/ArtifactBundle 若在 P0-A 为占位，本批补全（frozen/extra-forbid，Decimal 规范编码与 schema hash 锁定）。

==== P0-D：计算证据 / 验证 / 报告集成（方案 14.1，5–6 人日）====
1. 计算证据：evidence.py 把指标/估值结果结构化为 ComputationEvidence（引用 artifact + metric_path/row_keys、value/unit/definition、cell_hash）；validation.py 做计算一致性核验（改任一输入/输出hash、换unit/time、同源换包装均不得通过；重算匹配）。
2. 接入现有声明/验证/报告（严格增量、不改旧判定标准）：
   - 把投研结论作为“需验证声明”，证据从网页引文扩展为“数据快照+可复现计算+口径说明”；QuantitativeProfile 增加计算证据完整性/重算门禁，旧网页行为与 15 阶段政策保持；样本/校验/重要性/政策任一缺口不得 VERIFIED，不足通常 UNVERIFIED，不自动 PROBABLE。
   - reporting v2：ReportInputAssembler/assembler/models/hashing 增加量化语义材料的新域哈希（旧 v1 内容与哈希不变）；citations 增加计算引用分支（真实链 + 可定位 cell + 最新验证），旧引用不变；发布仍由确定性 policy 决定，新结论速览继续参与 probable/disputed 检查，不允许改名绕过门禁。
   - chinese_writer/writer/pipeline/renderer/persistence 追加投研块（数值只读、技术诊断只进折叠附录），沿用 answer-first、空章删除、局限聚合；事实/缺口全局只出现一次。
   - orchestrator/live_runtime：接入量化支路与取消收尾（量化 worker 取消后走同一终态，只有报告持久化才 COMPLETED），不改旧网页任务语义；不新增付费报告调用。
3. 数据缺失/部分结果：缺基准/rf 时不静默写零（可用户显式选零假设）；缺输入时产出部分报告并在局限说明，不伪称完整。
