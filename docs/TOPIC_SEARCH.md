# 主题输入与一键调查

首页以主题输入框替代多字段创建弹窗。用户输入主题后点击“开始调查”或按 Enter，前端依次创建调查档案、启动 LIVE 运行并显示调查进度；无需再次点击启动。标题与描述使用原始主题，目标与初始问题由明确的通用模板补充，不添加事件事实。

左侧历史档案保留；点击档案可查看已有结果，详情顶部也有新主题输入框。“调查新主题”返回首页并聚焦空输入框。成功启动后清空输入，失败保留输入。中文输入法选词时不会触发提交。

提交期间锁定按钮并隐藏旧结果。同一页面内重复点击共用一个请求；启动失败后的重试复用已创建档案，并先读取其运行列表，以处理启动响应丢失的情况。这不提供跨刷新、跨标签页的后端幂等保证。

## 验证

- 前端 13 项测试通过，包含创建后自动启动、空输入拒绝、重复提交合并、启动失败重试与响应丢失恢复；生产构建通过。
- 浏览器实测从首页输入主题后，自动产生档案 `INV-1087924830eb48d09063637b173ca217` 与 LIVE 运行 `RUN-LIVE-68e759dec0154171`，直接进入调查进度，未显示旧证据链。
- 历史档案可打开，返回首页后输入框自动聚焦；窄屏下输入和按钮上下排列，页面无横向溢出。
- 该真实运行取得 26 个来源、6 条证据、7 条候选声明，随后在 VERIFY 阶段因 `ValueError` 失败。此记录证明入口调用链已接通，不代表这次调查成功完成。后端验证阶段错误仍需单独定位修复。
